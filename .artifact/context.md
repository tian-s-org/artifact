# artifact 自举原型

artifact 自己的设计画布：Agent 写静态 HTML 画框 → `artifact push` → 浏览器只读查看。
这一轮先**复刻现在的产品页面**，作为后续改版的基线。

## 六屏

1. **个人中心 · 卡片**：登录后的画布列表，卡片视图；
2. **个人中心 · 列表**：同一页的列表视图；
3. **画布查看器**：无限画布、画框、工具条、尺寸 hover、头像；
4. **聚焦层**：双击画框后的浮层；
5. **全屏查看**：聚焦层里按 F 之后的样子；
6. **登录页**：未登录访问时的页面。

## 视觉

- 浅灰画布 `#f5f5f5`，白色内容区，强调色 `#007aff`；
- 圆角 10px，1px 分隔线，克制阴影；
- 工具条/头像用半透明白 + 背景模糊（玻璃质感）。
