# 内容平台架构图规范

这套画板用来评审「内容平台」的两个候选形态与部署方式，读者是工程与运营的混合评审。
基调是工程制图：白底、细线、字号偏小、信息密，颜色只用来区分方案与告警，不做装饰。

## 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#101318` | 标题、节点主文字 |
| `--ink-2` | `#5b6470` | 说明、次级文字 |
| `--ink-3` | `#8b95a1` | 标注、坐标、页脚 |
| `--line` | `rgba(16, 19, 24, 0.12)` | 框线、连线、分隔 |
| `--ground` | `#f4f6f8` | 画布底、成组区块 |
| `--a` 方案 A | `#2563eb` | 模块化单体 |
| `--b` 方案 B | `#0f766e` | 拆分服务 |
| `--warn` | `#b45309` | 风险、瓶颈、需要决策的点 |

一张画板里两个方案并排时，颜色是方案的唯一区分手段：别用两种以上强调色，也别给普通节点上色。

## 字体

- 正文与节点：系统无衬线，12–12.5px，行高 1.6。
- 标题 20px / 600；小节标题 15px / 600。
- 度量、端口、版本号、页脚一律等宽 11px；范围与耗时写在箭头旁，不写进节点。

## 间距

- 页头 `28px 44px 18px`，页脚 `12px 44px`，左右页边距 44px。
- 成组区块内边距 `24px 28px`，区块之间 20px。
- 连线尽量横平竖直，转角 90°；箭头只画在终点。

## 画板约定

- 尺寸按内容定：系统总览 1720×1000，请求时序 1440×900，部署拓扑 1600×1000。
- 页头左侧标题、右侧 `content platform · board-00N`；页脚右侧一句结论。
- 方案并排时左 A 右 B，两边标题栏对齐；结论只写一句，放在方案下方。
