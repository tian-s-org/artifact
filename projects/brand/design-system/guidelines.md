# Northstar 设计规范

Northstar 是第三波咖啡烘焙品牌。视觉基调是纸感、克制、只用一种暖色强调；版面留白大，标注一律走等宽小字。

## 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` 主墨 | `#1b1410` | 标题、标志、正文主色 |
| `--ink-2` 石褐 | `#6b5c50` | 次级正文、说明 |
| `--ink-3` | `#9a8a7c` | 标注、页脚、等宽小字 |
| `--line` | `rgba(27, 20, 16, 0.12)` | 1px 分隔线、网格线 |
| `--paper` 纸白 | `#f7f2ea` | 舞台底色 |
| `--surface` | `#ffffff` | 画板底色 |
| `--accent` 琥珀 | `#b45309` | 只做强调：虚线安全边距、强调标签、少量色块 |

用色比例：主墨约九成版面，琥珀不超过一成，纸白与石褐只做点缀。
琥珀不用于正文，也不铺大面积底色。

## 字体

- 正文与标题：系统无衬线（`PingFang SC` / `Helvetica Neue`）。
- 标注、编号、页脚：等宽（`SF Mono` / `Menlo`），11px，字距 0.12em 起，全大写英文徽标同字号。
- 层级：H1 64 / H2 40 / H3 28 / H4 20，字重 600；正文 14–15 / 400；标注 11。
- 字距从 -0.02em 起，标题最多收到 -0.04em，再紧就不像这个品牌了。

## 间距

- 页头 `34px 52px 22px`，页脚 `14px 52px`，左右页边距统一 52px。
- 舞台网格 80px，线用 `--line`。
- 组件间距用 10 / 12 / 16 / 22，不要再细分。

## 画板约定

- 画板 1440×900；页头左侧标题、右侧项目徽标（`NORTHSTAR · BRAND CORE · 0N`）。
- 页脚左侧 `northstar / board-00N`，右侧一句规则说明。
- 标志只出现单线星形 + 字标组合，安全边距按 1× 星形半径画虚线。
