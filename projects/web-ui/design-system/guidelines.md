# Relay 界面规范

Relay 是一个收件箱产品（邮件 + 会话 + 标签），这套画板是它的高保真界面稿。
基调是桌面客户端：浅灰底、白色卡片、1px 细线分区，字号小而密，信息优先于留白。

## 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#12161c` | 主文字 |
| `--ink-2` | `#5d6673` | 次级文字、摘要 |
| `--ink-3` | `#8d95a1` | 时间、计数、占位符 |
| `--line` | `rgba(18, 22, 28, 0.1)` | 分区线、表格线 |
| `--surface` | `#ffffff` | 主面板、卡片 |
| `--side` | `#f7f8fa` | 侧栏、列表底 |
| `--accent` | `#2563eb` | 主按钮、选中态、未读点 |
| `--accent-soft` | `rgba(37, 99, 235, 0.1)` | 选中行底、标签底 |

强调色只出现在「当前选中」与「主操作」上；未读用点，不用整行变色。

## 字体

- 全部系统无衬线；数值、快捷键、账号地址用等宽 11px。
- 层级：标题 13.5 / 600，正文 12.5 / 400，元信息 12 / 400，标注 11。
- 行高 1.5；列表行靠高度和分隔线区分，不加大间距。

## 间距

- 页面左右 28px，页头 `22px 28px 14px`。
- 列表行内边距 `0 10px`，行间距 10px；按钮与标签内边距 `0 9–11px`。
- 分组之间 8px，卡片内 6–10px。

## 画板约定

- 三栏主界面 1440×900，撰写弹层 1440×900（背后带主界面），设置表格 1024×768。
- 每块画板自带一份完整样式，`body` 铺满；不做 `transform: scale()` 适配。
- **画板之间是隔离的**：`board-002`、`board-003` 用了和 `board-001` 同名的 class（`.avatar`、`.btn`、`.group` 等）但色值不同——这是用来验证画板样式互不串的，不是新配色。新画板照 `board-001` 的色值来。
