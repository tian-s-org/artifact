# 这块画布的写作规范（给 Agent）

放在 `.artifact/AGENTS.md`，给之后在这个目录里继续干活的 agent 读。**画框标签由画布渲染，画板里不要自己写标题。**

## 先看这里：哪些别动

| 东西 | 谁维护 | 说明 |
| --- | --- | --- |
| `.canvas` | CLI | 画布 id 绑定，`push` 自动写；别改、别删，删了会新建一块画布。 |
| `layout.json` 的 `protocol` | 协议 | 固定 `1`。 |
| 画框 `id` 与目录名 | 你 | 要改就两边一起改。 |
| `assets/css/` 共享样式 | 你 | 能改，但影响所有画框。 |
| 画板里的脚本、外网资源 | 沙箱 | 硬约束：脚本不执行，外网被 CSP 拦。 |

**你该动的地方只有**：`layout.json` 的 `boards`、`artboards/`、`assets/`。

**原型就是事实来源**：要交代背景就画一块画板，不写 `context.md` 这类散文——改一次文档还要同步一次画板，两边迟早对不上。

## 画框标题与序号

- 标签格式：**`01 技能库`** —— 两位序号 + 一个空格 + 名称。
- 字号固定 12.5px（画布会按缩放反向缩放，24% 和 200% 下一样大）；画板里不要自己放大字号。
- 序号 = `layout.json` 里按 `order` 排完后的位置；新增画框插到正确位置，别一律追加。
- 名称 2–6 个字的名词短语，画什么写什么；不写尺寸、版本。
- 按模块编号时名称写成 `2.1 主界面`；画布自己的两位序号仍会加在前面（页面显示 `02 2.1 主界面`），这是已知叠加，别为此去掉模块号。
- 尺寸在悬停标签里显示：`01 技能库 · 1200 × 750`。
- 不要用 `Frame 1`、`未命名`、`board-001` 当显示名；`id` 只用于目录名和深链 `?focus=<id>`。

## 画框尺寸

- **没有统一尺寸这回事**：画布上会同时有界面、规格页、流程图、单张卡片，各自按内容定版面，具体尺寸自己拿捏。
- 一个画框对应一个真实的东西：界面用那台设备的屏幕尺寸，别为了排布去迁就；别的设备把尺寸写进名称。
- 只有同一个界面的多个状态/变体才保持同尺寸，方便并排比。
- **窗口 chrome（红绿灯、标题栏）只属于界面原型**——在画一屏真实软件界面时才套；
  规格页（设计系统 / 色板 / 图标表）、流程图、架构图、单张组件不套，版面按内容挑。

## 摆位

- **画布是自由的**：位置、行数、留白都由你定，没有规定的主流程方向；多屏就多开画框，不要塞进一个。
- 唯一要守的是亲和性：相关的画框靠近、不相关的拉开；两档间距一眼看出差别，不靠分隔线补分组，也不重叠。

## 设计系统就是规则

画布上如果有「设计系统 / 规范」画板，**它是硬约束**：新画板默认必须遵循，冲突时以它为准；
违反它算 bug。它本身要写成「祈使句 + 允许值 + 判据」的规则，而不是色板/字号/图标清单——
清单只能看，不能判定。没设设计系统时才用下面的通用基本功。

## 设计基本功（动笔前先过一遍）

《写给大家看的设计书》那四条是底线，不是建议：

- **对比**：不同的东西要完全不同——主次靠大小/粗细/明暗/字体类别拉开，两个都「中等」就没层级。
- **重复**：同一套视觉语言反复出现（按钮形态、字号档、间距、描边），不要每次重新发明。
- **对齐**：任何东西都不能随手摆，每条边都要对上；数字右对齐；不能出现「差 1px」的伪对齐。
- **亲密性**：相关的靠近、不相关的拉开，间距差本身就是分组。

再加三条：

- **焦点唯一**：一屏只有一个主角，用对比把它顶出来；人眼走 Z/F 形，别让人回头找。
- **颜色三层**：主色 + 强调色 + 中性色，大面积中性、强调面积越小越有力；
  不要只用颜色表达状态（红绿色盲约占男性 8%），状态点旁边配文字或形状；正文对比度 ≥ 4.5:1。
- **字体克制**：最多两种字体族（界面无衬线 + 等宽）；字号阶梯 4–6 档；正文行高 1.4–1.6，行长 45–75 字符。

自检：对比够 · 重复一致 · 对齐唯一 · 间距两档 · 焦点唯一 · 强调只一处 · 状态不只靠颜色 · 没有占位文案。

## 交互

- 只读画布：画板里不出现直接改动文件或仓库的控件（接受 diff、建 worktree、推送、合并、发评论）。
- 人只看、只跟 agent 说话；这些动作在原型里表现为「对 agent 说一句话」的输入行。

## 视觉

- 颜色、字号、圆角只取 `assets/css/` 里的令牌，不另造一套。
- 画板是静态 HTML：无脚本、不引外网、资源用相对路径。
- 放大要清楚：矢量 SVG、真文本、1px 边框。
- 图标内联成 sprite（`<symbol>` + `<use href="#id">`）：`sandbox=""` 下跨文件的 `<use href="xxx.svg#id">` 是跨源引用，不渲染。
  描边用 `currentColor`，尺寸用 class 控（12 / 14 / 18px）。

## 自检

改完先跑校验（`layout.json` 字段与画框文件），再 `artifact push`，刷新链接确认序号与标签。
